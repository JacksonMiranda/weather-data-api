# Política de Segurança / Security Policy

## Versões Suportadas / Supported Versions

| Versão / Version | Suportada / Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Relatando uma Vulnerabilidade / Reporting a Vulnerability

### Português (PT-BR)

Se você descobrir uma vulnerabilidade de segurança, por favor:

1. **NÃO** abra uma issue pública
2. Envie um e-mail para [jacksonmiranda.dev@gmail.com](mailto:jacksonmiranda.dev@gmail.com)
3. Inclua o máximo de detalhes possível:
   - Descrição da vulnerabilidade
   - Passos para reproduzir
   - Impacto potencial
   - Sugestões de correção (se houver)

Você receberá uma resposta dentro de 48 horas reconhecendo o recebimento do seu relatório. Manteremos você informado sobre o progresso da correção.

### English (EN-US)

If you discover a security vulnerability, please:

1. **DO NOT** open a public issue
2. Send an email to [jacksonmiranda.dev@gmail.com](mailto:jacksonmiranda.dev@gmail.com)
3. Include as much detail as possible:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fixes (if any)

You will receive a response within 48 hours acknowledging receipt of your report. We will keep you informed about the progress of the fix.

## Divulgação Responsável / Responsible Disclosure

Pedimos que você nos dê tempo razoável para corrigir a vulnerabilidade antes de torná-la pública. Geralmente, isso significa:

We ask that you give us reasonable time to fix the vulnerability before making it public. Generally, this means:

- 90 dias para vulnerabilidades críticas / 90 days for critical vulnerabilities
- 120 dias para vulnerabilidades de alta severidade / 120 days for high severity vulnerabilities
- 180 dias para vulnerabilidades de média/baixa severidade / 180 days for medium/low severity vulnerabilities
