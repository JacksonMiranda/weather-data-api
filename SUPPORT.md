# Suporte / Support

## Como Obter Ajuda / How to Get Help

### Português (PT-BR)

Existem várias maneiras de obter ajuda com este projeto:

#### 🔍 Documentação
Primeiro, verifique a documentação disponível:
- [README.md](./README.md) - Visão geral e guia de início rápido

Para perguntas gerais, discussões sobre funcionalidades ou ideias:

1. ✅ Leia a documentação / Read the documentation
2. ✅ Procure por issues existentes / Search for existing issues
3. ✅ Forneça informações detalhadas sobre seu problema / Provide detailed information about your problem

5. ✅ Especifique sua versão do Node.js, Docker, etc. / Specify your Node.js, Docker, etc. versions
